## What we collect

You can read every page on sendforless without giving us your name, email address, or a newsletter subscription. We do not operate a mailing list on this site. We do not ask you to create an account.

If you email [hello@sendforless.com](mailto:hello@sendforless.com), we receive whatever you put in that message, including your address and any details you volunteer. We use it to answer you or to correct a price. We do not sell that email, add it to a marketing list, or pass it to MailCheap. Delete requests go to the same address. We will remove the correspondence we still have, except where we need to keep it for a legal obligation.

The site is hosted as static files. A host’s ordinary server logs can include an IP address, a browser type, and the page requested. We do not use those logs to build a profile, and we do not sell them. Hosting is set up so the site can be deployed on Vercel. Vercel’s own processing, if the deployment uses it, is described in Vercel’s privacy policy. Analytics, which we do add, is described below.

## Cookies and analytics

Every page loads Google Tag Manager, container `GTM-TFBLV8WQ`. We do not load Google’s `gtag.js` file ourselves. The container includes Google Analytics 4, measurement ID `G-G7X8CD2S9Y`. Google Analytics sets cookies, including `_ga` and related cookies, and receives usage data: the page you view, a rough location derived from your IP address, and device and browser information. We use that to see which guides are read.

When you click a link whose host is `mailcheap.ai` or a subdomain of it, the page pushes one `affiliate_click` event onto the Tag Manager data layer. The event includes the link URL (`link_url`), the visible link text (`link_text`), and the page path (`page_path`). Tag Manager forwards that event to Google Analytics. The page does not send a second copy. It is not a record of whether you bought a plan.

The cost calculator still runs in your browser. The subscriber count you type is not sent as its own field. We do not sell analytics data. Google’s processing is described in [Google’s privacy policy](https://policies.google.com/privacy). You can block the tag with your browser or with an extension that blocks Google Analytics.

## Affiliate links

A click on a MailCheap affiliate link takes you to MailCheap. From that moment MailCheap’s site, cookies, and privacy policy apply. The link includes a `via` parameter so MailCheap can attribute the referral. That parameter identifies the site, not you. We do not receive your MailCheap account details, list, or payment information.

Other outbound links go to the companies named in the sentence. Their policies apply on their sites.
